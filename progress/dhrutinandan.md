## Notes for Dhrutinandan
- Onboarding now also saves eyewear, past eye test and its note (`Profile.eyewear`, `.pastEyeTest`, `.pastEyeNote`, `.relation: "self"`).
- Login (token + user), settings and calibration are saved on the phone with AsyncStorage (`store/auth.ts`, `store/settings.ts`, `store/calibration.ts`), so a restart stays logged in and calibrated. The token is stored unencrypted; `expo-secure-store` would encrypt it (not added). Settings → Offline data → Clear forgets the calibration. Mock data (profiles, history) still resets on restart, as it stands in for the server.
- No guest mode: every user needs an account ("Continue as guest" removed from Welcome and Log in). Screens can assume `currentUser()` is set.
- "Start my first eye check" (onboarding) goes to Home until Issue intake (group 3) exists.
- Mock auth accepts any credentials.
- Test detail text for 13 of the 14 tests is written by Claude (the design only has Distance acuity). It lives in `apps/mobile/src/constants/tests.ts`; edit freely. Non-E tests show their category icon as the illustration.
- Shared types extended on 2026-10-21 (optional fields only, nothing removed): `ScoredResult.eyes` (`EyeResult` per eye), `.meaning`, `.tip`, `.field` (peripheral dots, `FieldDot`); `Verdict.date`, `.minutes`; new `SessionSummary` (with `tests` and `scores`), `SessionMode`, `ShareLink`; `LensSuggestion` and `EyeResult` types exported. `docs/API.md` says which screen reads what ("What the result screens read"). The server scorers should fill the optional fields; screens hide a section when a field is missing.
- Home buttons not wired yet: quick check "Start" (→ Quick check, Phase 2), Screen time card (→ Screen Coach, Phase 3, mock numbers for now).
- Calibration shows the bank card upright (short edge, 53.98 mm, across the screen): the design's sideways card can't be matched at real size because 85.6 mm is wider than a phone. `pxPerMm = card width in points / 53.98`. Saved on the phone. Face-distance check with the camera is Phase 3.
- Intake follow-up questions (eyes, how long, pain/flashes) are fixed in the app; the answers go to the server as part of `intake` text (`Eyes: …`, `How long: …`, `Pain, redness or flashes: …`). "Yes, flashes" is not treated as a red flag in the app: red flags come from server rules.
- Instructions text for all 14 tests is in `constants/tests.ts` (`INSTRUCTIONS`). Distance acuity follows the design; the rest are written by Claude. Note: the design's Tumbling E test screen says "Phone placed 2 m away · helper answers" but its instructions say arm's length (40 cm); group 4 will follow the instructions (40 cm, user answers).
- Between-test (14) and Red-flag (15) still show one result card; they can use `ScoredResult.eyes` now that it exists (small follow-up).
- Analysing footnote: the design's "Analysed on your phone. Nothing is uploaded." breaks the wording rule; it says "Your results are saved securely to your account." instead.
- Red-flag "Find eye doctors nearby" opens a Google Maps search; "Save report" opens the share sheet with a short text report.
- Added `zustand` (stores in `src/store/`), `expo-speech` (Listen on instructions), `expo-print` + `expo-sharing` (report PDF), `react-native-qrcode-svg` (report QR), `@react-native-async-storage/async-storage` (saved login/settings/calibration) and `expo-notifications` (monthly check reminder, local only), all Expo Go. In Expo Go on Android, the first time the reminder switch is used the console shows a yellow "push notifications unavailable in Expo Go" warning; local reminders still work.
- Test answer shapes are written in `docs/API.md` ("Answers format per test") for the teammate's scorers. One-eye-at-a-time tests send one result with `eye: "both"` and `answers: { right, left }`.
- Tumbling E runs at 40 cm (arm's length, user answers), not the design's "2 m · helper answers". E sizes come from `pxPerMm` (5 arcmin at 6/6), rounded to whole device pixels; lines the screen can't draw distinctly are skipped and the real size is sent. Answer by arrow buttons or by swiping on the E.
- Between eyes the run screen shows Switch eye (44): read aloud, then a 3-second countdown starts the left eye ("I'm ready" skips it). Exit (X or Android back) shows Exit confirmation (46).
- Colour plates and Kids colour shapes are generated in code (packed dots, figure decided by maths: digits are thick strokes, shapes are polygons), because the design draws them on a web canvas. They are screening plates, not calibrated Ishihara plates. Plate 1 of each is a demo everyone should see.
- Near point: the design reads distance live from the camera (Phase 3, needs a development build). For now the user brings the phone closer, taps "It's blurry now", then sets the distance on a slider (`distanceSource: "manual"`).
- Near reading: N-scale sizes from calibration at 40 cm (big lines wrap, the list scrolls). Hindi and Odia use the phone's own font (Figtree has no Devanagari/Odia).
- Peripheral: 24 dots, 2.25 mm (about 0.43° at 30 cm), shown 400 ms after a random 0.9–1.7 s pause; a tap within 1.5 s counts. Positions are sent in mm from the centre dot.
- Peripheral field map (58): one cell per dot (the 24 dots alternate outer/inner ring every 15°, so each owns a 30° slice), seen light, missed black, left eye first. It sits inside Test result detail (18) and Single test complete (48).
- Tests are drawn with `react-native-svg` and plain views, not Skia (`@shopify/react-native-skia` isn't installed; not needed so far). They live in `src/tests/` (one component per test, `TESTS` map in `tests/index.ts`).
- Contrast letters are 5 mm tall from calibration and shuffled each time; each letter's contrast is sent with the answer. Amsler areas can be tapped or painted by dragging.

- Results (17) has no link to Lens (19) in the design; it uses the screen 61 pattern: black "See lens suggestions" + plain "Done" under it. Area tiles show only the areas tested today (the design's "Colour · Looks good · Jul" needs past checks). Check length in minutes is counted in the app from the plan start.
- Results (17), Lens (19), Test result detail (18) and Share report (20) take the verdict from the check store right after a check, otherwise from `GET /sessions/:id` (`useVerdict` in `store/check.ts`), so past checks from the Results tab open too. Closing Results right after a check ends it and goes Home; for a past check it just goes back.
- Share report: the link comes from `POST /sessions/:id/share` (mock link `https://visus.app/r/…`, which opens nothing until the web report page exists). Download PDF makes the PDF with `expo-print` and opens the share sheet to save or send it, so the button then says "PDF ready" (not the design's iOS-style "PDF saved to Files"). WhatsApp opens WhatsApp with the text report + link, or the share sheet if WhatsApp is missing. Lens "Show at store" opens Share report, as in the design.
- Results tab: trend tabs follow Distance acuity (Sharpness), Contrast and Colour plates scores over the last 6 checks that include them; "See all" expands the list in place (there is no separate all-checks screen). Mock history: 6 past checks May–Oct plus the checks you take. Test result detail shows "86 on 12 Oct" from the latest earlier check with that test. Single tests (from Test detail) end on Single test complete (48), also after a red flag; Retake on 18/48 starts that test again.

- Text size (Settings): Default / Large / Larger scale every font by 1 / 1.12 / 1.25 (`components/Text.tsx`) and grow buttons, options and chips (`TextSizes` in `constants/theme.ts`; Large matches the design's large text mode). Calibrated test symbols (E art, contrast and duochrome letters, near-reading lines, near-point line) use `FixedText`, which also fixes an old issue: Android's own font size used to change those mm sizes.
- Profile (6): family chips switch the card and the "My eyes" / "Riya's eyes" section. Glasses = eyewear + prescription (R/L sphere) → My glasses; Last check = that person's latest check → its Results (none → starts a check); Saved lens = the lens saved with "Save" on Lens suggestions (owner's profile) → that lens screen. The design shows a prescription under "Saved lens"; the app shows the saved ZEISS lens there and the prescription under Glasses.

Check reminder = real monthly local notification at 10:00 (asks permission; if refused, a note links to phone settings); it starts off. Break reminders and Weekly report are saved but start with Screen Coach (Phase 3), as the note under the card says. Offline data = the saved screen calibration (Clear forgets it). Log out asks for a second tap, cancels the reminder and returns to Welcome.
